# Layout Documentation: Blog Page

**Intent:** An editorial hub for beauty tips, academy news, and bridal trends.

## Sections
1. **Header:**
   - *Rhythm:* `py-20`, left aligned.
2. **Featured Article:**
   - *Rhythm:* Large prominent card, 2/3 image, 1/3 text split.
3. **Category Filter:**
   - *Rhythm:* Sticky horizontal bar, minimal padding.
4. **Article Grid:**
   - *Rhythm:* 3-column grid, `gap-12`.
   - *Components:* Article cards (Image, Date Overline, Serif Title, Read More link).
5. **Newsletter Signup:**
   - *Rhythm:* Full width banner, centered content.
   - *Components:* Simple input field and button.
6. **Pagination:**
   - *Rhythm:* Centered, standard spacing.
