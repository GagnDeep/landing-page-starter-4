# Layout Documentation: Careers Page

## Section Architecture & Rhythm
Aimed at professionals looking to join a high-quality, friendly team.

### 1. Hero: Join Our Team
- **Rhythm:** Image of staff interacting happily.
- **Intent:** Show a positive workplace culture.

### 2. Why Work With Us? (Culture)
- **Rhythm:** 3-column feature grid (e.g., Work-life balance, modern tech, training).
- **Intent:** Sell the clinic as an employer.

### 3. Open Positions List
- **Rhythm:** Accordion or list with expansion for details.
- **Intent:** Clear listing of current needs (e.g., Hygienist, Front Desk).

### 4. Application Process
- **Rhythm:** Simple timeline.
- **Intent:** Set expectations for candidates.

### 5. General Application Form
- **Rhythm:** Standard form with file upload for resume.
- **Intent:** Capture talent even if a specific role isn't listed.
