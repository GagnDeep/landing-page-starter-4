# FAQ Page Layout

## Intent
To address common patient concerns immediately, covering medical, logistical, and financial questions.

## Sections
1. **Hero:** "Frequently Asked Questions". Search bar for quick answers.
2. **Category Jump Links:** Emergency, Treatments, Insurance, Appointments.
3. **Emergency Care FAQ:** Accordion (e.g., "What counts as a dental emergency?").
4. **Treatments FAQ:** Accordion (e.g., "Is teeth whitening safe?").
5. **Logistics & Financial FAQ:** Accordion (e.g., "Where can I park?").
6. **Still Have Questions? (CTA):** Direct link to Contact page or quick-call button.
