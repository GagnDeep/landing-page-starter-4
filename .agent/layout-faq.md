# FAQ Page Layout Structure

## Goal
Address client and student concerns efficiently in a clean, easily navigable format.

## Sections
1. **Hero:** Simple title, search bar for finding specific questions.
2. **Quick Links/Categories:** Jump links to specific sections (Booking, Courses, Policies).
3. **Salon FAQ:** Accordion list for clients.
4. **Academy FAQ:** Accordion list for students.
5. **Still have questions? (CTA):** Card with contact info and a link to the Contact page.
