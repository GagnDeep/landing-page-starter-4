# Layout: FAQ Page

## Structural Intent
To address common patient concerns comprehensively, reducing support calls and pre-emptively handling objections.

## Sections

1. **Hero Header:**
   - *Intent:* Set a helpful tone.
   - *Rhythm:* Simple header "Frequently Asked Questions". Search bar integration if applicable.

2. **Quick Links / Categories:**
   - *Intent:* Fast navigation.
   - *Rhythm:* Anchor links to sections (General, Pediatric, Billing, Specific Procedures).

3. **General FAQs:**
   - *Intent:* Basics about the clinic.
   - *Rhythm:* Accordion list. (e.g., Hours, Location, What to bring).

4. **Pediatric FAQs:**
   - *Intent:* Address parent anxieties.
   - *Rhythm:* Accordion list. (e.g., When should my child first visit? Do you allow parents in the room?).

5. **Treatment / Painless Care FAQs:**
   - *Intent:* Address fear.
   - *Rhythm:* Accordion list. (e.g., Are root canals painful? What sedation do you offer?).

6. **Billing & Insurance FAQs:**
   - *Intent:* Financial clarity.
   - *Rhythm:* Accordion list.

7. **Still Have Questions? (Contact Block):**
   - *Intent:* Provide a fallback if their question isn't answered.
   - *Rhythm:* Form or direct contact info prominent at the bottom.
