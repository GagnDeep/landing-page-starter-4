# Layout Documentation: FAQ

## Intent & Visual Rhythm
The FAQ page prioritizes utility and scannability. It should be clean, organized, and straightforward.

## 1. Hero: How can we help?
- **Intent**: Friendly, supportive introduction.
- **Layout**: Centered header, possibly with a search bar if content is extensive.

## 2. Categorized Accordions
- **Intent**: Group questions (e.g., Booking, Home Services, Salon Policies).
- **Layout**: Vertical list of expandable accordion items, separated by categories.
- **Visuals**: Smooth expansion animation. Clear, legible Body text.

## 3. Still have questions? (Contact CTA)
- **Layout**: Small call-out box directing to the contact page.
