# About Page Layout Structure

## Goal
To tell the story of 99 Institute, connecting the physical salon in Patiala with the broader vision of high-end beauty and education.

## Sections
1. **Hero:** Full-width atmospheric shot of the studio or founder, overlay text.
2. **The Origin Story:** Editorial layout detailing how the institute started.
3. **Mission & Vision:** Bold typography block, strong statements on beauty and education.
4. **Our Philosophy:** 3-column grid highlighting core tenets.
5. **Meet the Team:** Grid of key artists/instructors with hover state bios.
6. **The Patiala Studio:** Image gallery showing the physical location's luxury.
7. **Awards & Recognition:** Logo strip or badge grid.
8. **Join the Movement (CTA):** Push to Careers or Academy pages.
