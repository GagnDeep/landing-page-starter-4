# Features (Services) Page Layout Structure

Detailed breakdown of medical procedures.

1.  **Hero:** "Specialized Dental Care."
2.  **Service Categories Menu:** Sticky sidebar or tabs.
3.  **Service 1 Detail (e.g., Implants):** Description, technology used, benefits.
4.  **Service 2 Detail (e.g., Aesthetics):** Description, technology used, benefits.
5.  **Service 3 Detail (e.g., Orthodontics):** Description, technology used, benefits.
6.  **Patient Journey:** How treatments are planned.
7.  **Technology Stack:** Highlight specific machines/tools (e.g., 3D scanners).
8.  **CTA:** Schedule a consultation.
