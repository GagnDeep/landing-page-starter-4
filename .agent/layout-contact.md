# Contact Page Layout Structure

## Goal
Provide clear avenues for communication, location details, and a seamless inquiry form.

## Sections
1. **Hero:** Clean, minimal header.
2. **Contact Grid:** 3 cards (Call Us, Email, Visit Us) with large icons.
3. **Inquiry Form:** A sleek, multi-step or well-organized form for different intent (Bridal vs Academy).
4. **Interactive Map:** High-quality map integration showing the Patiala location.
5. **Social Links:** Large, stylized links to Instagram, Facebook, etc.
