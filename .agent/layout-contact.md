# Layout Documentation: Contact Page

**Intent:** Functional but elegant. Make it easy to find location and reach out.

## Sections
1. **Header:**
   - *Rhythm:* `py-20`, left aligned.
2. **Contact Grid:**
   - *Rhythm:* 2-column grid. Left: Form. Right: Info & Map.
   - *Components:*
     - Left: Clean form fields, minimalist styling.
     - Right: Address, Phone, Email, Operating Hours, embedded map.
3. **Location Details:**
   - *Rhythm:* Specific directions or parking info.
4. **Social Links:**
   - *Rhythm:* Large icon grid or stylized list.
