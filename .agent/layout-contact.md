# Layout Documentation: Contact Page

## Section Architecture & Rhythm
The most conversion-focused page next to the Home page. Must be frictionless.

### 1. Hero / Header
- **Rhythm:** Direct, welcoming.
- **Intent:** "We're here for you."

### 2. Primary Contact Methods
- **Rhythm:** Grid of 3 large distinct blocks (Phone, Email, Address).
- **Intent:** Make essential info impossible to miss.

### 3. Contact Form
- **Rhythm:** Clean, well-spaced input fields.
- **Intent:** Allow users to send inquiries directly. Include a 'Reason for visit' dropdown.

### 4. Interactive Map & Directions
- **Rhythm:** Large embedded map.
- **Intent:** Visual location confirmation and route planning.

### 5. Operating Hours / Emergency Info
- **Rhythm:** Clear tabular format. Highlight emergency protocols.
- **Intent:** Prevent frustration regarding when the clinic is open.
