# Contact Page Layout

## Intent
Make it incredibly easy for users to reach out, find the clinic, or get immediate emergency help.

## Sections
1. **Hero:** "We're Here for You, 24/7".
2. **Emergency Contact Block:** Highly visible phone number and "Call Now" button.
3. **Contact Form:** Fields for Name, Email, Phone, Subject, Message.
4. **Clinic Details:** Address, standard operating hours (and emergency hours), general email.
5. **Map Integration:** Interactive Google Map pinpointing the Chandigarh location.
6. **Social Links:** Links to Instagram, Facebook, etc.
