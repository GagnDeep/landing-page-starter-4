# Layout: Contact (`/contact`)

This document defines the structural blueprint and visual rhythm for the Contact page.

## 01. Pre-Header Announcement
- **Intent**: Sitewide banner.
- **Visual Rhythm**: Tight, high contrast.

## 02. Navigation Header (Solid)
- **Intent**: Standard navigation.
- **Visual Rhythm**: Solid background.

## 03. Contact Hero
- **Intent**: Simple, direct introduction.
- **Visual Rhythm**: Minimal text, plenty of whitespace.

## 04. Primary Contact Info
- **Intent**: Phone, Email, Address.
- **Visual Rhythm**: Three-column grid, large icons.

## 05. The Map
- **Intent**: Visual location cue.
- **Visual Rhythm**: Full-width or large embedded map container.

## 06. Opening Hours
- **Intent**: Clear listing of availability.
- **Visual Rhythm**: Clean table layout.

## 07. Contact Form Header
- **Intent**: Introduce the form.
- **Visual Rhythm**: Subheading.

## 08. The Contact Form
- **Intent**: Primary communication method.
- **Visual Rhythm**: One-column form, floating labels, large inputs.

## 09. Form: Name Field
- **Intent**: Input.
- **Visual Rhythm**: Standard input styling.

## 10. Form: Email/Phone Fields
- **Intent**: Input.
- **Visual Rhythm**: Side-by-side inputs on desktop.

## 11. Form: Subject Dropdown
- **Intent**: Categorize inquiry.
- **Visual Rhythm**: Custom select component.

## 12. Form: Message Area
- **Intent**: Main text input.
- **Visual Rhythm**: Large textarea.

## 13. Form: Submit Button
- **Intent**: Action.
- **Visual Rhythm**: Prominent button.

## 14. Parking Information
- **Intent**: Practical advice for arrivals.
- **Visual Rhythm**: Small text box with an icon.

## 15. Public Transit Info
- **Intent**: Practical advice.
- **Visual Rhythm**: Bullet points.

## 16. Social Media Links
- **Intent**: Alternative contact/following.
- **Visual Rhythm**: Row of large social icons.

## 17. Press Inquiries
- **Intent**: Direct media contacts.
- **Visual Rhythm**: Small text block.

## 18. Emergency/Urgent Info
- **Intent**: What to do if they need immediate help.
- **Visual Rhythm**: Subtle warning banner.

## 19. Main Footer
- **Intent**: Navigation.
- **Visual Rhythm**: Dark background.

## 20. Sub-Footer
- **Intent**: Legal.
- **Visual Rhythm**: Minimal.
