# Layout Documentation: Services & Pricing

## Intent & Visual Rhythm
The pricing page must be incredibly easy to navigate. It should reduce the cognitive load of browsing complex beauty menus while maintaining the elegant brand feel.

## 1. Hero: Services Menu
- **Intent**: Simple title and optional category anchor links.
- **Layout**: Centered, clean typography. Sticky category navigation below the header.

## 2. Category Blocks (e.g., Hair, Skin, Nails)
- **Intent**: Group services logically.
- **Layout**: Stacked sections. Each section has a large heading, followed by a list or grid of specific services.
- **Visuals**:
  - Each item shows the Service Name, Duration, and Price.
  - Optional "Add to booking" or "Book this" inline buttons.
  - Subtle borders separating items.

## 3. Memberships / Packages (Optional)
- **Intent**: Highlight high-value bundled offerings.
- **Layout**: Highlighted cards (e.g., 2 or 3 column grid).
- **Visuals**: Distinct background color (`surface-secondary` or a dark variant) to make packages stand out from a la carte services.

## 4. FAQ (Pricing Specific)
- **Intent**: Address common booking/cancellation questions.
- **Layout**: Accordion style.
